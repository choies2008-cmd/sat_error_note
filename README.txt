사문 오답 분석 앱 1.0.0

파일
- index.html : 화면 구조
- style.css : 디자인 / 모바일 반응형
- app.js : 기록, 통계, 백업/복원, 저장 로직

사용법
1. index.html을 브라우저에서 열거나 GitHub Pages에 세 파일을 올립니다.
2. 데이터는 브라우저 localStorage에 저장됩니다.
3. 설정 > 데이터 백업에서 JSON 파일을 만들어 별도로 보관하세요.
4. 설정 > 데이터 복원에서 JSON 백업을 추가하거나 교체할 수 있습니다.

현재 AI 기능
- 아직 연결하지 않았습니다. 분석 > AI 학습 상담에는 준비 상태만 표시됩니다.

주의
- 브라우저 사이트 데이터 삭제/시크릿 모드/기기 변경 등에 대비해 백업 파일을 보관하세요.
- 그래프는 외부 라이브러리 없이 canvas로 그립니다.
